# Student Launcher (legacy)

> **This project moved.** Student Launcher is now **Calm UI**, developed in the open at
> **[github.com/jainam6610/calm-ui](https://github.com/jainam6610/calm-ui)**.
>
> Active development, issues, releases and documentation live in the new repository.
> The Google Play listing is unchanged: **https://play.google.com/store/apps/details?id=com.studentlauncher**

## Why this repository still exists

`privacy.html` at the repository root is the privacy-policy URL that existing Play
installs of Student Launcher point to. It stays published here so those installs keep
a working, honest policy. The current policy for Calm UI is served at
**https://jainam6610.github.io/calm-ui/**.

The source tree here is frozen at the last student-only release. Do not open pull
requests against it — use [jainam6610/calm-ui](https://github.com/jainam6610/calm-ui).
